# Trabajo Final — Juan Bautista Xifro

Repositorio del Trabajo Final de Ingeniería en Sistemas de Información (UAI, 2026): evaluación comparativa de modelos de lenguaje para atención al cliente.

## Estructura

- `proyecto/`: entregable ejecutable. Contiene código, notebook, corpus, resultados, pruebas, dependencias declaradas y la única versión vigente de la tesis.
- `gestion/`: contexto de trabajo, planes, hallazgos, scripts auxiliares, presentación y material de referencia para el desarrollo y los agentes.

Las instrucciones de instalación y ejecución están en [`proyecto/README.md`](proyecto/README.md).

Los archivos locales `proyecto/venv/` y `proyecto/.env` no se versionan: el entorno se recrea desde `proyecto/requirements.txt` y las credenciales nunca deben subirse.
